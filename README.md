One line, in the voice of the Moon finally answering back: "Four billion years of wishes, howls and 2 a.m. promises, and not one of you has ever wished me a good night." The program writes exactly that line (108 characters) to `/output/entry.txt`. It answers all three things the brief names — the wishes, the howls, the late-night promises — then turns the bargain around: everyone has asked the Moon for something for four billion years, and nobody has ever wished the Moon itself a good night.

## Run it

```sh
python3 main.py
```
